## ⑦ 자세 리포트 구현에서 확정되지 않은 항목
- Figma에 없는 문구 상황은 해당 문장을 만들지 않고 숨긴다: 왼쪽 우세·균등 균형 문장(수치 기준 미확정), 중간·앞꿈치 우세 "보이는 점", 측정 품질 줄, "측정 예시" 접미사(예시 데이터에만).
- Report Loading/Error 프레임이 Figma에 없어 구현하지 않았다.
- 집계 규칙은 해석이다(SDK·기획 확인 필요). 확정된 5개 정책과 남은 미확정은 아래 "⑦ 확정된 정책 5개"·"⑦ 남은 미확정"에 정리했다.
- Figma의 47:53, 62:30:8, 55%→53%는 디자인 예시이며 어떤 경로로도 앱에 쓰이지 않는다(테스트로 보호).
- SDK 연결 지점: SDK 요약을 `PostureSummary`(`features/running/postureSummary.ts`)로 변환해 기록 생성(`buildRunRecord`)에 넘기면 된다. 현재 `buildRunRecord`는 `sensorReport: null`을 쓰므로 실제 측정 데이터는 아직 생기지 않고 화면은 항상 No data이다.

### ⑦ 확정된 정책 5개 (2026-11-23 반영 완료, 코드·테스트와 대조함)
1. **지난주 비교(A)**: 최근 7일 (now−7일, now]과 직전 7일 (now−14일, now−7일]을 비교한다. 두 구간은 겹치지 않고(정확히 7일 전 시각은 직전 7일), 한쪽에 양쪽 측정 기록이 없으면 비교를 만들지 않는다. 28일 분석 기간과는 별개이다. (`COMPARE_DAYS`, `buildPostureReport`)
2. **한쪽 측정 압력(B)**: 한쪽 측정 기록도 압력 분포·최근 3회에 포함하고, 좌우 균형에는 쓰지 않는다. 반대쪽 값은 추정하지 않는다.
3. **4주 집계(C)**: 최근 28일, 유효한 기록만, 기록마다 같은 가중치(날짜 가중 없음), 미래·손상 기록 제외. 균형은 양쪽 측정 기록만 쓴다.
4. **상태별 문구(D)**: 수치 기준이 코드·명세에 없어 아래 "남은 미확정"에 둔다(문구를 새로 만들지 않았다).
5. **품질·측정 예시(E)**: SDK가 품질을 주기 전에는 품질을 표시·평가하지 않고, "측정 예시"는 예시 데이터에만 붙인다. 현재 자세 리포트에는 예시 데이터가 없어 표시하지 않는다.

### ⑦ 남은 미확정
- **좌우 우세·균형 문구(D)**: 후보 문구 3개는 있으나 "우세"와 "균형"을 가르는 수치 기준(예: 50%에서 몇 %p 차이부터 우세)이 없다. 현재는 Figma에 있는 "오른쪽 비중이 50%를 넘을 때 몇 %p 높은지" 문장만 쓰고, 왼쪽 우세·균형 문장은 기준이 정해질 때까지 표시하지 않는다. 기준이 정해지면 후보 문구를 쓰되 진단 표현은 피한다.
- 최소 기록 수 기준(현재 1건이면 표시), Report Loading/Error 프레임, SDK 계약 전체(필드·단위·구역·품질 필드)는 미확정이다.

## ⑧ 안내 설정 연결에서 확정되지 않은 항목
- 자동 일시정지 발동 조건(D14): 승인 전이라 구현하지 않았다. 스냅샷의 `autoPause` 값만 세션에 고정해 둔다.
- 안내 설정의 박자·음성·빈도는 읽어 동작하는 기능(음악 재생, TTS, 빈도 판정)이 아직 없어 스냅샷만 저장한다(`features/running/runGuidance.ts`). 각 기능은 구현될 때 `getSessionGuidance(activeSession)`로 시작 시점 설정을 읽는다.
- 준비 화면(`ReadyPage`)의 "음성 안내 · 켜짐" 줄은 Figma 문구를 그대로 쓴 정적 표시라 안내 설정을 꺼도 "켜짐"으로 보인다. 설정과 맞추려면 문구표(꺼짐일 때의 문구)가 필요하다. 이번에 바꾸지 않았다.
- 스냅샷이 없는 이전 저장 세션은 기본값(전부 켜짐, 벗어날 때만)으로 읽는다. 시작 당시의 실제 설정은 알 수 없다.

## ⑧ 자동 일시정지·Ready 음성 안내 (마무리)

- Ready 화면 "음성 안내" 꺼짐 문구: Figma(RUN / Ready)에는 켜짐 문구만 있다. 꺼짐은 같은 형식의 임시 문구 `꺼짐 · 진동은 이 기기에서 지원하지 않아요.`를 쓴다. 후보: (a) 그대로 `꺼짐 · …`, (b) `꺼짐 · 설정에서 켤 수 있어요.`, (c) `꺼짐`만. 확정 필요.
- 자동 일시정지 시 화면 안내 문구는 만들지 않았다(기존 일시정지 화면 그대로). 자동/수동 구분 문구는 미확정.
- 자동 일시정지 정지 기준(0.5 km/h 미만·10초)은 확정 정책이다. 실제 GPS 지터로는 두 좌표 사이 속도가 기준 미만으로 안 내려갈 수 있어 실기기 확인이 필요하다.
