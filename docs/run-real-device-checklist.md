# Run 실기기(iPhone) 검증 체크리스트 (#48)

자동 테스트(`node --test`)는 가상 GPS와 가짜 시계로 로직만 검증한다. 아래 항목은 **실제 iPhone Safari에서 사람이 확인해야 하며, 아직 수행하지 않았다.**
수행하면 결과 칸에 통과/실패와 확인한 날짜·기기·iOS 버전을 적는다.

## 준비

- 위치 API는 보안 컨텍스트(HTTPS)에서만 동작한다. HTTPS 개발 서버로 열고 iPhone과 PC를 같은 Wi-Fi에 둔다.
- 자체 서명 인증서 경고를 허용하고, Safari의 위치 서비스·로컬 네트워크 권한을 확인한다.
- 기기·iOS 버전, 확인 날짜를 기록한다.

## 알려진 한계

- 웹 앱은 화면이 꺼지거나 백그라운드에 있는 동안의 위치 수집을 보장하지 못한다. 화면에서 이를 보장한다고 표시하지 않는다.
- 새로고침 복원은 제품 범위에서 제외했다. 새로고침하면 진행 중인 러닝은 이어지지 않는다.
